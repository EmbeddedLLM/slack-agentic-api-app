# Local model examples

Generated by the app's `create_sticker` function using the local `Qwen/Qwen3.8-27B-FP8` model:

- `dancing-cat.gif`: text prompt → model-drawn frames → 256 × 256 animated GIF, 13,880 bytes.
- `source-cat.png`: first frame of that generated artwork, used as an image-input fixture.
- `cat-from-image.gif`: image plus “make this cat wiggle” → local image animation, 53,078 bytes.

These are sample outputs, not guaranteed artwork quality for every prompt. Run `npm run sticker:smoke` to try your own description; add `-- --image ./picture.png "make this wiggle"` for an image.
